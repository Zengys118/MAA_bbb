# MAA_bbb

基于 **miaojiuqing/Maa_bbb** 修改的《崩坏3》自动化小助手，由 **MaaFramework** 驱动。

主要是自己在原项目基础上继续折腾，目前重点增加和完善了 **往世乐土自动流程**。

感谢原项目作者淼九清老哥，以及 MaaFramework 和相关项目的开发者。

## 目前主要改动

### 往世乐土自动化

在原有 Maa_bbb 乐土流程基础上继续扩展，目前加入了关内自动流程，包括：

- 自动战斗
- 刻印选择
- 自动选门 / 寻门
- 角色移动
- 商店流程
- 逐层推进
- 关卡状态判断
- 通关后重新接回原有任务流程

目前仍然在持续测试和调整，不同角色、配置以及游戏环境下可能还会出现一些奇怪的问题。

## 其他功能

原 Maa_bbb 已有的日常任务等功能基本保留。

本仓库目前主要集中在往世乐土部分进行修改和扩展。

## 使用

目前项目仍处于个人开发和测试阶段。

如果只是想直接使用，建议优先使用 Releases 中提供的打包版本；源码主要用于开发、调试以及交流。

具体使用方式和乐土相关配置后续会继续补充。
