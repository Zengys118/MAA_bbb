# 往世乐土使用说明

## 推荐入口

在小助手中选择安卓端 MuMu，勾选正式的「往世乐土」任务。不要同时勾选「自动战斗」「自动战斗 Pro」或「往世乐土 · 开发测试（MuMu）」，避免多个流程同时控制游戏。

当前关内流程适配「窈窕谍影·华裳」。脚本不会替换游戏中的角色、装备、助战或难度，请在开始任务前自行完成这些准备。

## 可配置项

- **战斗角色**：选择角色出招表。当前提供窈窕谍影。
- **角色流派**：选择华裳流派。角色出招表和流派配置由关内引擎读取。
- **战前增益选择**：沿用小助手原有的战前增益设置。
- **真我刻印自选**：留空时使用角色推荐；填写后按配置顺序尝试选择。
- **刻印优先级**：可逐项设置普通刻印的优先顺序；关闭时使用角色推荐。
- **门的选择优先级**：可逐层设置英桀门优先级；关闭时由角色策略和已获得刻印决定。
- **商店策略**：可选择自动购买适合当前流派的刻印，或绕过商店不购买。

## 自动流程

原版流程负责进入往世乐土、完成战前增益并启动第一层。识别到初始刻印页面后，关内引擎接管：

1. 跳过入场对话并选择初始真我刻印。
2. 按角色出招表进行战斗，识别通关结果和刻印页面。
3. 按当前层的刻印优先级选择刻印；没有目标时使用备用选项并继续流程。
4. 识别门的位置，移动角色并点击目标门；视角或目标丢失时执行恢复和重新搜索。
5. 在商店层按配置购买或绕过，并继续下一层。
6. 完成第 17 层后进入英桀房间并退出结算，返回原版流程领取周常奖励。

脚本支持从舰桥、乐土大厅、深层序列战前页面或已经在关内的楼层继续。停止任务时会释放摇杆；如果识别失败，请先停止任务并保留现场截图和日志再反馈问题。

## 分辨率和连接

使用 MuMu 的安卓端资源，游戏和模拟器保持 16:9 分辨率，并确认 ADB 已连接。发布仓库只包含示例配置；设备地址、运行日志和本机配置不会提交。
